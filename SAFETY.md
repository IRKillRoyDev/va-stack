# Safety

- **Not legal or medical advice.** This project produces organized research notes only. It does not decide entitlement, predict ratings, or diagnose anything.
- **Verify with an accredited professional.** Before acting on any output, review it with a VA-accredited representative, a Veterans Service Organization (VSO), or a VA-accredited attorney or claims agent. Accreditation can be checked at https://www.va.gov/ogc/apps/accreditation/.
- **No filing.** The bot never submits, files, signs, or transmits a claim, form, or document to VA or anyone else. The user decides what, if anything, to file.
- **Where records go.** Record files are stored only in the folder the user chooses. The skills never commit, upload, or copy those files anywhere else. However, the text the bot reads from them is processed by the AI service the bot runs on, so it does leave the machine. Check that service's privacy terms before using real records. A fully offline setup needs a local model. To limit what is sent, the local-search skill runs `scripts/local_search.py` on the user's computer (no network calls, nothing written to disk) and returns capped, redacted snippets; the user approves the snippet list before any of it goes to the AI service, and whole pages are read only with explicit approval. Redaction is pattern-based and can miss things. Names are not automatically redacted, including third-party names; review each snippet before approving it. Outputs redact anything the user does not need (SSN, VA file number, DOB, addresses, phone numbers, unrelated third parties).
- **Primary sources only.** Every legal statement cites its primary source, fetched in the same session with an "as of" date: 38 CFR (eCFR API), the U.S. Code (govinfo), DoD instructions (official DoD issuances site), or live VA.gov pages. Nothing is cited from memory. If a fetch fails, the bot stops.
- **No guessing.** If evidence is missing or ambiguous, the bot says so and lists it as a gap.
- **Crisis support.** If you are a veteran in crisis, or worried about one, contact the Veterans Crisis Line: dial 988, then press 1 (or text 838255, or chat online). Sources, checked 2026-10-16: https://www.veteranscrisisline.net/ and https://www.va.gov/health-care/health-needs-conditions/mental-health/. If you are in immediate danger, call 911.
- **No real patient data in this repo.** Everything under `tests/` is fictional.
